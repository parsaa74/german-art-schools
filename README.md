# German Art Schools

A quiet guide to art, design, film, music and media programs at German schools: deadlines, teaching languages, application routes and costs, taken from official pages.

**Live:** https://parsaa74.github.io/german-art-schools/

This is an independent project, not an official source. Admission rules change, so confirm details on the school's own page before applying.

## Development

Requires Node.js 20+.

```bash
npm install
npm run dev     # http://localhost:5173/german-art-schools/
npm run build   # dist/
```

A read-only API for the same data lives in [`api/`](api).
